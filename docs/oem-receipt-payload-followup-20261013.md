# 푸미 OEM 입고의 원가 근거 전달

## 실제 누락

입고 모달과 OEM 엔진은 사용자가 확인한 원가 근거를 `oemCostEvidence`로 전달한다. 그러나 관리자 앱의 서버 호출 어댑터에서 이 필드를 빼고, 서비스 요청 타입에서도 빠져 있었다. 서버는 이미 근거가 있으면 최초 입고에 고정하고 없으면 미확인 원가로 입고를 허용하므로, 이번 수정은 입력한 근거가 실제 서버까지 도착하도록 연결하는 범위다.

## 범위

관리자 실제 콜백과 `receiveOemFinishedGoodsCommand`의 공용 타입을 연결한다. 원가 근거가 없으면 기존 요청을 유지한다. 수량·날짜·가공 단가·작업 번호·전환 설정은 바꾸지 않는다. 실제 콜백을 추출해 실행하고 서비스 callable payload를 대조하여 중간 누락을 검출한다.

이번 수정은 벌크 OEM 입고 지원 전체와 다르다. 벌크는 화면에서 입력을 허용하지만 엔진·서버가 거절하는 문제가 별도로 남아 있다. 원료 코어를 재사용한 단일 transaction과 가공비 후확정의 벌크 원입고 로트 소비까지 연결해야 한다. 오래된 실패 요청의 입력 변경도 서버 결과 증거를 확인한 뒤 처리해야 하며, 오류 문구나 영수증 부재만으로 자동 삭제하지 않는다.

## 검증 상태

원가 근거 전달 구현과 관련 시험 5건이 통과했고, 전달 필드를 제거한 변이에서 실패를 확인한 뒤 원복했다. 벌크 입고 후속도 같은 릴리즈로 통합 검수 중이며 아직 배포하지 않았다. 이전 주문3건의 수동 잠금 해제는 DB 변경 기록에 별도로 남겨 이 기능 수정과 구분한다.
