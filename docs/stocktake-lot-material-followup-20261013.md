# 실사 이월 로트의 물질 정보

2026-10-13. 기존 변경을 보존한 후속 검증이며 배포하지 않았다.

실사로 신규 이월 로트를 만들 때 품목에 저장된 `material` 또는 `rawMaterialName`을 공용 `stocktakeLotMaterial`에서 읽어 남긴다. 완제품 이름으로 원료를 추정하지 않는다. 같은 공용 로트 앵커를 앱과 서버가 사용한다.

번호 없는 기존 이월 로트는 OEM 번호를 소비하지 않으므로 물질 이름이 없어도 신규 OEM 번호 발행을 막지 않는다. 실제 OEM 번호가 있는 로트의 물질 불명확성은 중복 위험이 있어 보존한다.

기존 로트·운영 수량·물질 이름을 일괄 보정하지 않는다. 신규 이월 생성과 OEM 번호 사용 판정을 각각 검증하며, 실사 원장과 품목 재고의 원자 저장 경로는 그대로 유지한다.
