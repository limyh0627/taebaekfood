## 공유 전송 원문

최초 방·직원·로그인UID·본문·작성시각·파일 SHA256을 업로드 전에 보존한다. 업로드된 URL까지 완성한 메시지를 보존한 뒤 공유UUID를 명시해 전용 저장으로 전달한다. 실제 로그인 회사/employeeId와 방 참여를 확인하고 같은ID의 기존문서는 업무 원문이 정확히 같을 때만 duplicate로 판정한다. 반응 등 기존 부가필드를 덮지 않는다. 일반 메시지 쓰기 경로를 변경하지 않는다.

응답 유실이나 공유 캐시 삭제 실패 뒤 재마운트에서도 최초 방과 원문을 유지한다. File 캐시가 없어도 완성 원문으로 결과 확인에 진입한다. 회사/UID가 바뀌거나 원문이 다르면 덮어쓰지 않으며, 저장 성공 확인 뒤 공유 캐시와 정확 pending을 정리한다. Android 실제 공유 시트 인수는 별도 미완료다.
