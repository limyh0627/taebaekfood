# 9월 9일 원료 출처 확인의 후속 범위

2026-10-15. 외주 원물 금액 근거 화면 및 재고·로트 대조와 함께 처리하는 세 건 묶음의 읽기 진단이다. 과거 생산량이나 원료 사용을 추정해 운영 자료를 고치는 작업은 아니다.

10월 9일에 보존한 해당 주문의 조사 원문을 SHA로 고정한 뒤, 같은 주문 한 건의 현재 원문과 새로 저장된 명시 연결만 확인한다. 시작·끝 주문, 기존 거래처·박스 품목·낱개 품목·연결 전표가 기본 여섯 GET이다. 현재 저장 원문에 명시된 원장·작업 참조만 추가하며 전체 GET 상한은 62건이다. 전체 주문·원장 질의, 현재 BOM을 이용한 과거 역산 및 원래 없던 작업 경로 추정은 하지 않는다.

정상적인 문서 부재와 조회 실패를 구분한다. 끝 주문의 전체 typed 원문·나노초 버전이 바뀌면 연결 결과는 미확인으로 남긴다. 연결 문서가 있다는 사실만으로 미취소·현재 유효성·최초 요청 지문이나 실물 생산량까지 확인했다고 설명하지 않는다. 주 문서의 사후 동치 역시 모든 연결 문서를 원자적으로 읽었다는 증명이 아니다.

원문·식별자·관측 시각은 기존 파일을 덮어쓰지 않는 비공개 결과에 보존하고, 이 문서에는 범위·집계·한계만 남긴다.

## 이번 확인 결과

집중 시험 20개, 좁은 타입 검사, 실제 Node22 자체검증과 쓰기 인자 사전 거절을 통과했다. 끝 주문의 나노초 대조 보호 제거 의미변이를 검출·원복하고 독립 검수를 마친 뒤 운영 읽기를 정확 한 번 실행했다.

실제 GET은 기본 여섯 건으로 끝났으며 모두 문서가 존재했다. 시작·끝 주문 원문과 버전이 일치하고 기존 조사와 달라진 필드는 없었다. 추가 원장·작업을 직접 가리키는 저장 참조도 없어 추가 GET은 하지 않았다. 저장 결과의 원문 해시·고정 기준 원문·조회 범위는 별도로 독립 대조했다.

이는 새 생산 출처를 찾지 못했다는 결과다. 실제 생산이 없었다거나 원료를 누락했다는 증명이 아니다. 원본 TODO는 실제 생산·기존 완제품 사용 근거 확인이 남아 전체 완료로 바꾸지 않는다. 운영 자료·원본 백업 변경은 없다.
