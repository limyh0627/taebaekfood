## 실제로 수행한 최소 검증

2026-10-16에 기존 소스와 fixture를 읽고, 파일을 생성하지 않는 메모리 번들로 현재 순수 함수만 실행했다. `oemExternalCostDiagnostic.test.ts`의 fixture 함수와 `oemIssueJob.ts`의 지문 함수는 TypeScript AST로 추출했으며 함수 본문을 새로 복제하지 않았다. 진단·공용 원료 지문·평가기는 현재 소스를 esbuild `write:false`로 묶었다. Firebase 서비스나 운영 자격 증명을 불러 실행하지 않았다.

대표 확인7개가 통과했다. 이 결과를 미래 시나리오12개 통과나 새로운 제품 시험7개 추가로 세지 않는다. 명시0·취소 등 나머지 현재 경계는 기존 시험 본문을 읽어 연결했으며 이번에 재실행했다고 기록하지 않는다. 기존 시험의 이전 통과 수와 중복 합산하지 않는다.

첫 `node --import tsx` 직접 실행은 로컬 ESM/CJS 모듈 경계에서 `kstDateOf` export 오류로 함수 실행 전에 종료됐다. 제품 파일을 고치지 않고 메모리 번들 경로로 검증을 마쳤다. 첫 실행은 성공 근거가 아니며 이 문서 작업에서 별도 제품 결함을 수정·완료했다고 주장하지 않는다.
