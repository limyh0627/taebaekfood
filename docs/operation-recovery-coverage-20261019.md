# 업무별 실제 처리 상태 확인과 복구 종결

기준 커밋: `f74acf2da71916b49e9d2bbbbc2366ee116b862d`. 이 문서는 코드 연결 조사표이며 운영 자료의 처리 상태나 배포 완료를 뜻하지 않는다.

사용자 요구는 모든 업무에서 실제 처리 상태를 알아내고, 그 결과에 맞는 다음 행동까지 끝낼 수 있게 하는 것이다. 미확정 안내나 서버 처리 기록만 있어서는 완료가 아니다.

## 공통 완료 조건

| 확인한 실제 상태 | 이어져야 하는 처리 |
| --- | --- |
| 같은 요청 처리 완료 | 해당 요청의 화면·기록만 완료 처리한다. 새로 작성한 내용은 보존한다. |
| 확정 거절 | 이유와 고칠 항목을 알리고, 내용을 수정해 새 요청을 만들 수 있다. |
| 서버 처리 기록 없음 | 실패로 단정하지 않는다. 동일 요청 재시도 또는 늦은 실행도 막는 중단을 제공한다. |
| 중단 확정 | 미처리 동일 요청의 뒤늦은 실행을 막고 새 작성으로 돌아간다. |
| 일부 단계 완료 | 이미 끝난 업무는 반복하지 않고 남은 단계만 확인·재개한다. |
| 손상되거나 다른 기기 사본 | 요청 번호로 실제 결과를 확인한다. 적용된 업무와 기기 사본 정리를 구분한다. |

입력 오류는 송신 전에 설명한다. 서버가 이미 거절한 경우와 연결이 끊겨 결과를 모르는 경우를 구분한다. 목록에 항목이 없다는 사실만으로 이전 요청의 실패나 중단을 확정하지 않는다. 복구 때문에 무관한 업무를 잠그지 않는다.

## 18차에서 연결한 범위

위 조사표의 주문 편집·품목/BOM 편집에서 다른 유효 사본 및 손상 사본 때문에 서버 결과를 조회하지 못하던 경로를 보완했다. 서버 요청 번호로 실제 결과를 확인한 뒤 기기 원문을 별도로 대조한다. 다른 사본의 완료를 현재 초안의 완료로 오인하거나 자동 삭제하지 않는다.

주문은 명시 사본 정리 후에도 정리 완료 안내를 남긴다. 품목은 다른 원문의 일부 완료 상태를 현재 진행률에 합치지 않고, 남은 단계 중단과 종결 확인 후 사본 정리로 이어진다. 사본 정리는 기존 업무·사진·새 초안에 영향을 주지 않는다. 실제 관리자 부모에서 주문 목록·배송 화면과 품목 복구 목록까지 새 포트를 전달한다.

관련 고유 74건과 의미 변이 9건을 검증했고 별도 담당의 독립 검수를 거쳤다. PC·390픽셀 합성 화면에서 실제 복구 UI·후크·저장 어댑터에 통신이 차단된 합성 서버를 연결해 결과 확인→중단→사본 정리를 확인했다. 운영 자료나 실기기로 시험한 것은 아니다. 이 결과는 독립 수금·지불·문서함·공지·나머지 저장의 공백을 해소했다는 뜻이 아니다.

## 19차에서 연결한 범위

독립 수금·지불의 재열기 복구를 연결했다. 기존 서버 영수증과 현금 최초 생성 이력의 검증을 공용으로 사용해 조회·미처리 중단을 처리한다. 모달은 현재 잔액이나 날짜로 이전 원문을 다시 만들지 않는다. 완료된 상계를 재실행하지 않는다. 위 조사표의 독립 수금·지불 행은 수정 전 발견 기록이며 이 절이 현재 검증 범위다.

과거 기기 원문이 완전히 손상돼 요청 번호도 없으면 특정 서버 요청과의 동일성을 자동 확정할 수 없다. 현재 회사·로그인 UID·거래처로 제한된 서버 처리 이력을 조회해 실제 처리 기록을 확인하도록 연결한다. 비슷한 금액·날짜나 조회 결과 부재로 요청의 성공·실패를 추정하지 않는다. 식별 불가 기기 사본을 정리하는 것은 서버 요청 중단이나 금융 기록 취소가 아니다. 이후 송신은 원문과 별도 요청 번호 기록을 보관한다.

관련 고유 239건(실제 로컬 SDK 71건 포함)과 의미 변이 12개를 검증했다. 독립 검수에서 재시도 후 금융 반영은 끝났지만 기기 사본 정리에 실패한 경우 창이 닫히던 경로를 발견해 보완했다. 완료된 금융 업무를 다시 실행하지 않고 남은 정리만 확인한다.

실제 모달·후크·전송 어댑터에 합성 SDK를 연결하고 운영 통신을 차단한 PC·390픽셀 화면에서 확인했다. 100원 반영 뒤 응답 유실→닫기→현재 잔액 70원·다음 날짜로 변경→재열기에도 원래 100원 요청을 유지하고 결과 확인으로 추가 반영 없이 종료했다. 미처리 응답 유실은 조회 후 중단을 확정하고 잠금을 풀어 새 작성으로 이어졌다. 상계 내역 컴포넌트는 이 합성 화면에서 분리했으며 실제 상계 회귀는 별도 시험 근거다. 실기기 검수는 사용자 지시로 제외했다. 운영 자료와 배포는 변경하지 않았다.
