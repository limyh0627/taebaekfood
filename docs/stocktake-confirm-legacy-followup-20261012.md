# 제품 실사·발주확정·더미 전표 경로 후속 · 2026-10-12

이번 묶음은 011 / INBOUND-RETURN / 017의 추가 안전 보완이다. 원본 전체 완료는 새로 인정하지 않으며 전체 집계는 21완료·22잔여를 유지한다.

## 변경

- 제품 실사 최초 입력과 요청 ID를 회사·사용자·품목별로 보존한다. 제출한 요청은 저장 원문 앵커를 조회하며, 근거가 없으면 재고를 다시 적용하지 않는다. 새 실사 앵커만 원문을 남기며 기존 앵커는 재작성하지 않는다. 응답 유실 뒤 출고나 최소재고 변경이 있어도 최초 목표값을 다시 덮지 않는다.
- 일반 발주확정은 최신 발주 회사·직원 권한·업무 원문·상태를 한 거래에서 확인한다. 이미 같은 원문으로 확정되었다면 기존 시각을 보존한다. 입고완료·취소·삭제·원문 변경은 거절한다. 거래처를 첫 매입처로 임의 추정하지 않는다.
- 옛 더미 전표 CLI의 원격 접속과 생성·삭제 명령을 제거한다. 읽기 미리보기 안내만 제공하며 쓰기 인수는 실패 코드로 거절한다.
- 독립 검토에서 발견한 늦은 실사·입고 UI 응답의 회사·품목·상세 세대 보호를 보완한다.
