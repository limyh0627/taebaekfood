# 과거 주문 조회 응답 순서 후속

같은 회사에서 월별 주문 조회를 시작한 뒤 전표 메뉴의 전체 주문 조회를 시작하면, 전체 응답이 먼저 완료돼도 늦게 도착한 월 응답이 전체 목록을 좁힐 수 있었다. 실제 공용 훅의 조회 함수를 지연 응답으로 실행해 재현했다. 사용자가 보고한 특정 주문 누락의 원인으로 단정하지 않는다.

완료된 조회 범위가 새 범위를 포함하면 기존처럼 조회를 생략한다. 진행 중인 범위가 새 범위를 포함하면 같은 요청을 공유한다. 진행 중 범위에 포함되지 않는 새 조회만 새로운 요청으로 시작하고, 현재 요청만 자료·완료 범위·진행 상태를 바꾼다. 전체 조회 중 월 조회가 들어와도 전체 조회를 공유하며, 월 조회 뒤 전체 조회가 들어오면 전체 조회가 최종 상태가 된다. 포함되지 않는 두 범위는 최신 요청을 채택하는 기존 단일 범위 모델을 유지한다.

회사·로그인 허용 상태·실제 인증 세대와 화면 종료도 응답 반영 조건에 포함한다. 실패한 조회를 완료 범위로 기록하지 않으며 기존 자료를 보존해 같은 범위를 다시 요청할 수 있도록 한다. 기존 Promise 오류 전달 계약·한국 날짜 범위·회사 조건·실시간 자료 우선 병합은 유지한다. 운영 주문이나 재고는 수정하지 않는다.

제품은 src/shared/hooks/useAppData.ts와 기존 useAppData.test.tsx, AdminApp.tsx와 기존 historicalMonthDates 시험의 네 파일이며 이 문서까지 정확 다섯 파일이다. 관리자 진입점은 회사·UID 변경 때 재마운트를 보장하지 않으므로, 원료수불부·전표의 기존 조회 effect는 새 loader callback을 의존성에 포함해 같은 화면에서도 새 세대의 이력을 다시 읽는다. 조회 범위와 금액·수량 계산은 바꾸지 않는다. 집중 훅 회귀·보호 제거 변이·독립 검수·합성 화면·타입·양 앱 빌드·배포 결과는 완료한 단계만 이어 기록한다.

공용 훅 동결 후 실제 renderHook 이력 13개와 기존 선급금·단위 회귀 4개로 3파일 17개가 통과했다. 월→전체의 두 응답 순서·전체→월 및 같은 범위 요청 공유·비포함 범위 최신 응답·실패 재시도·이전 finally·회사/로그인 허용 상태/실제 UID 변경·같은 batch 인증 A→B→A 직후 재호출·언마운트 경계를 포함한다. 요청 세대 보호 제거 2개, 진행 요청 공유 제거 1개, 인증 콜백 동기 무효화 제거 1개 회귀가 실패해 보호를 확인했고 원본 바이트 복원 후 17개를 재통과했다. 인증 비교 하나만 제거한 변이는 다른 세대 보호가 남아 통과했으므로 검출 성공으로 세지 않는다. 부모 소비자와 최종 검증 결과는 아래에 구분해 기록한다.

부모 두 effect는 loader 의존성 두 줄만 보완했다. 기존 월 범위 2개와 실제 effect 본문·의존성을 함께 사용하는 React 회귀 2개로 4개를 통과했고, 각 의존성 제거는 해당 회귀가 검출했다. 공용 훅을 합한 고유 4파일 21개 집중 시험이 통과했다. 제품 4파일 최종 독립 검수 CLEAR이며 훅의 나머지 242줄이 기존 본문과 동일함도 대조해 다른 구독·계산의 유실이 없음을 확인했다.

총괄 최종 CUA 검수는 실제 useAppData 훅과 합성 서비스의 경계를 사용했다. 월→전체 요청에서 전체 응답을 먼저 완료한 뒤 옛 월 응답을 완료해도 전체 범위 자료가 유지됐다. 로그인 세대 전환 뒤 전체→월 요청은 실제 추가 조회 1건을 공유했고, 현재 요청 오류 뒤 loading=false로 해제돼 같은 범위를 새로 요청하고 성공할 수 있었다. 운영 연결을 차단한 합성 자료이며 원격 주문을 읽거나 수정하지 않았다. 사진은 저장소 밖 records/historical-order-race-synthetic-20261015.png다. 부모의 자동 재조회 연결은 별도 실제 effect 회귀로 검증했다.

최종 앱 타입 검사와 관리자·직원 앱 빌드(PWA 포함)가 모두 통과했다. 제품·시험 네 파일 SHA가 동결본과 일치하고 최종 148파일 manifest를 보존했으며 FCM 원문도 복원했다. 집중 21개는 이미 통과한 최종 코드의 결과를 재사용했고 전체 시험을 반복하지 않았다. 이 빌드를 그대로 배포한다.
