# 메인비즈(경영혁신형 중소기업) 인증 신청 체크리스트

> 근거: 중소기업 기술혁신 촉진법 제2조 4의2호 / 신청처: 메인비즈넷(smes.go.kr/mainbiz)
> 작성일: 2026-07-14

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 신청자격 | 중소기업 + **업력 3년 이상** |
| 통과 기준 | 온라인 자가진단 **600점 이상** → 현장평가 **700점 이상**(1,000점 만점) |
| 수수료 | 신규 55만원 / 연장 44만원 (VAT 포함) |
| 소요기간 | 현장평가 신청 후 3주 이내, 전체 3~4주 (서류 준비 기간 제외) |
| 유효기간 | 3년 |
| 절차 | 기업등록 → 자가진단 → 현장평가 신청 → 현장평가 → 발급승인 → 확인서 발급 → 사후관리 |

---

## 0단계. 자격 게이트 — 먼저 확인 (하나라도 걸리면 신청 불가)

- [ ] 사업자등록증상 **개업일 기준 3년 경과**
- [ ] 중소기업기본법상 중소기업 해당 (중소기업확인서로 확인)
- [ ] 제외업종 아님 (도박게임기·담배도매·숙박·주점 등) — **식품 제조/유통은 해당 없음**
- [ ] **부채비율 1,000% 미만** (재무제표 확인)
- [ ] **완전자본잠식 아님**
- [ ] 국세·지방세 체납 없음
- [ ] 금융기관 연체·거래정지 처분 없음
- [ ] 파산·회생절차 진행 중 아님

---

## 1단계. 계정 개설 및 자가진단

- [ ] 메인비즈넷 회원가입 (공동인증서 필요)
- [ ] 기업정보 등록
- [ ] **온라인 자가진단 실시** → 600점 미만이면 현장평가 신청 자체가 불가
- [ ] 600점 미달 시: 감점 항목 리스트업 → 3단계 문서 정비 후 재진단

> 자가진단은 "우리가 이렇게 하고 있다"고 체크하는 방식.
> **체크한 항목마다 현장평가에서 증빙을 요구**하므로, 증빙 없는 항목은 체크하지 말 것.
> 부풀려 체크하면 현장평가에서 그대로 감점됨.

## 2단계. 제출서류 발급 (1단계와 동시 진행 가능)

| 서류 | 발급처 |
|---|---|
| 사업자등록증명 | 홈택스 |
| 법인등기부등본 | 인터넷등기소 |
| 주주명부 | 자체 작성 (법인인감 날인) |
| 최근 3개년 재무제표 (표준재무제표증명) | 홈택스 / 세무사 |
| 중소기업확인서 | 중소기업현황정보시스템(sminfo.mss.go.kr) |
| 4대보험 가입자명부 | 사회보험통합징수포털 |
| 국세납세증명서 | 홈택스 |
| 지방세납세증명서 | 위택스 |
| 기업소개서 | 자체 작성 |
| 조직도 / 업무분장표 | 자체 작성 |
| 경영계획서 | 자체 작성 |
| 취업규칙 · 인사관리규정 | 자체 작성 |

## 3단계. 점수가 나오는 내부 문서 만들기 ★ 실제 작업의 90%

대부분의 기업이 여기서 막힘. 서류 발급은 하루면 끝나지만, 아래는 **없으면 새로 만들어야 함**.

### 3-1. 전략기획 및 이행관리
- [ ] **중장기 경영계획서** (3~5개년: 비전/미션/전략목표/연도별 KPI)
- [ ] 연도별 사업계획서
- [ ] 계획 대비 실적 분석 문서 (전년도분)
- [ ] **경영회의록** — 월간/주간, 최소 6개월치 이상 누적 (날짜·참석자·안건·결정사항)

### 3-2. 성과관리
- [ ] KPI 지표 정의서 (매출, 원가율, 불량률, 납기준수율, 재고회전율 등)
- [ ] KPI 측정 실적표 (월별 추이)
- [ ] 3개년 재무성과 추이 (매출·영업이익)
- [ ] 원가절감 / 생산성 개선 사례 (Before → After, **숫자로**)

### 3-3. 조직 및 인력관리
- [ ] 조직도 (최신)
- [ ] 업무분장표 (직무별 R&R)
- [ ] 취업규칙 (10인 이상 시 노동청 신고본)
- [ ] 인사평가·보상 규정
- [ ] **교육훈련 계획 및 실적** — 사내교육 일지, 외부교육 이수증
- [ ] 복리후생 제도 문서

### 3-4. 사회 신뢰 활동 (ESG) — 2026년 지표 개편으로 비중 커짐
- [ ] 노사협의회 회의록 또는 정기 직원 간담회 기록
- [ ] **안전보건·위생 관리 기록** — HACCP 운영 기록, 위생점검일지가 그대로 증빙됨 (식품업 강점)
- [ ] 사회공헌 활동 (기부금 영수증, 지역사회 활동 사진·기록)
- [ ] 환경 활동 (폐기물 감축, 에너지 절감, 친환경 포장재 전환 등)

### 3-5. 프로세스·정보화 혁신 ★ 태백푸드가 가장 강한 항목
현재 개발 중인 사내 ERP(품목·BOM 배합식·출고·거래명세서·손익·현금흐름)가 **경영혁신 활동 증빙 그 자체**임. 반드시 문서화할 것.

- [ ] 시스템 도입 배경 및 목적 문서 (도입 전 문제점 → 해결 목표)
- [ ] **도입 전/후 정량 비교표**
  - 월마감 소요시간: 수기·엑셀 O일 → 시스템 O시간
  - 재고 오차율: O% → O%
  - 거래명세서 발행 시간, 원가 산출 리드타임
  - 절감 인건비 환산액
- [ ] 시스템 화면 캡처 + 사용자 매뉴얼
- [ ] 개발 이력 (Git 커밋 로그 = 지속적 개선 활동 증빙)
- [ ] 향후 고도화 로드맵 (OEM 재고처리, 박스/낱개 재고 모델 등)

## 4단계. 현장평가

- [ ] 현장평가 신청 + **수수료 55만원 납부**
- [ ] 평가기관 배정 (신용보증기금 / 기술보증기금 / 한국생산성본부)
- [ ] 평가일 확정 (신청 후 3주 이내 방문)
- [ ] **증빙 바인더 준비** — 자가진단 항목 순서대로 문서 인덱싱
- [ ] 대표 인터뷰 준비: 경영혁신 스토리 3분 요약 (문제 → 시도 → 결과, 숫자 포함)
- [ ] 사무실·생산현장 정리 (평가위원이 현장을 직접 봄)
- [ ] **700점 이상** 획득 → 발급 승인

---

## 5단계. 발급 후 — 혜택 실제로 챙기기

- [ ] 확인서 발급 (유효기간 3년)
- [ ] **공공조달 신인도 가점** — 물품구매 2점, 제조업 2.5점 (조달청 나라장터 등록 시 반영)
- [ ] **정기 세무조사 유예** — 수도권 2년 / 지방 3년
- [ ] **보증료율 0.1%p 인하** (신보), 부분보증비율 최대 85%
- [ ] 은행 기업대출 금리 우대 (NH농협 최대 1.65%p)
- [ ] 병역지정업체 선정 시 4점 가점
- [ ] 방송광고 70% 할인
- [ ] **만료 3개월 전 연장 평가 신청** (44만원)

## ⚠️ 주의사항

1. **평가지표 개편** — 2026년 6월 지표가 개편되어 사회 신뢰 활동(ESG)이 정식 항목으로 강화됨. 공식 사이트 내에서도 구/신 체계 설명이 혼재하니, **신청 직전 메인비즈넷 자료실에서 최신 평가지표 원문을 반드시 다운로드**할 것.
2. **증빙 없는 자가진단 체크는 독** — 현장평가에서 그대로 감점된다.
3. **회의록·교육일지는 소급 작성이 티남** — 지금부터 매달 쌓아두는 게 가장 확실하다. 신청을 3개월 뒤로 잡고 그동안 기록을 축적하는 편이 낫다.
