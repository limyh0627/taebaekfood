# 로트 목록 높이와 카드 정리 · 2026-11-01

로트 이력의 별도 세로 스크롤 높이 제한을 없애고 페이지 스크롤을 사용한다. 기존 검색·날짜·정렬·페이지당 30건과 데이터는 유지한다.

품목 카드 안의 소진된 로트 전체 목록은 제거했다. 이력에서 종료 로트 하나를 직접 선택한 경우에는 그 로트만 읽기 전용으로 표시한다. 활성 로트 관리와 별도 로트 이력은 유지하며 실제 로트 삭제·재고·원가 변경은 없다.

집중 시험 6파일 65건을 통과했다. 격리한 실제 React 화면의 PC 1440px·모바일 390px에서 이력 67건의 3페이지 접근, 중첩 세로 스크롤 없음, 선택 종료 로트 한 건 표시, 운영 쓰기 없음과 입력 자료 불변을 확인했다. 이전 높이 제한을 되살린 검수용 변이는 실제 중첩 스크롤 검사로 검출했다.

앱 타입 검사·서버 컴파일·런타임 검사·관리자 및 직원 앱 빌드를 통과했고 기존 FCM 파일은 보존했다. 배포는 하지 않았다.
