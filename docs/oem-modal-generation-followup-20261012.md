## 현재 발견한 차이와 구현 범위

OemManager의 공용 run은 await 뒤 무조건 onClose와 busy 해제를 실행한다. 사용자가 요청 A를 보낸 뒤 모달을 닫고 다른 배치 B를 열면 A의 늦은 성공·실패·finally가 B의 입력이나 처리 상태에 영향을 줄 수 있다. 회사·모드·배치·열림 세대를 대조하고 현재 모달의 요청만 후행 상태에 반영하는 기존 UI 생명주기 보완을 구현한다. 입고 원자 명령·가공비 분개·원가 배분은 새로 계산하지 않는다.

과거 fix-boxsize-restore CLI는 boxSize를 유일한 환산 근거로 가정하여 고정값을 되살리고 undo에서는 무조건 삭제한다. 현재 unitsPerBoxOf는 BOM과 item_pack만 사용하고 shared/types.ts의 boxSize 제거 계약과 이 CLI 전제는 맞지 않는다. 실행 경로만 안내로 종료하며 과거 DB 변경 기록·백업과 현재 환산 모델은 보존한다.

## 현재 관계와 검증 예정
