# 재고·로트 차이 읽기 진단의 후속 범위

2026-10-15. 외주 원물 금액 근거 화면 및 과거 주문 출처 확인과 함께 처리하는 세 건 묶음의 읽기 진단이다.

10월 1일 대조는 6호박스 한 품목의 숫자 재고와 활성 로트 차이, 로트가 없는 완제품 12개와 캔 1개를 별도 확인 대상으로 남겼다. 현재 확보한 자료에는 뒤의 13개 품목 ID 명단이 없다. 이번에는 ID가 확인된 태백 6호박스 한 품목만 대조한다. 현재 품목을 새로 선정해 옛 13개와 같은 대상이라고 설명하지 않는다.

품목의 시작·끝 원문과 명시된 로트의 발주 참조만 읽는다. 품목 두 GET과 명시 발주 최대 100 GET, 해당 품목 입고 기록 질의 한 회로 제한한다. 입고 기록은 101번째 문서가 발견되면 부분 성공 없이 중단하며, 로트는 최대 1,000개로 제한한다. 공용 로트 잔여 수량 계산의 단위를 그대로 사용하고 kg·병·박스를 추정 환산하지 않는다.

최종 품목 원문·나노초 버전이 바뀌면 결과는 미확인이다. 현재 숫자가 같더라도 과거 차이의 원인, 실물 일치 또는 원본 TODO 전체 해결을 의미하지 않는다. 입출고 일부 문서만으로 과거 전체 재고를 역산하지 않으며 로트나 재고를 자동 생성·수정하지 않는다. 자료·관측 원문은 비공개 파일에 보존한다.

## 이번 확인 결과

집중 시험 21개, 좁은 타입 검사와 실제 Node22 자체검증을 통과했다. 끝 품목 대조 보호 제거 변이에서 회귀가 실패함을 확인하고 복원했다. 독립 검수를 마친 뒤 등록된 읽기를 한 번 실행했다. 실제 GET 두 건과 한정 입고 질의 한 회였으며, 해당 입고 문서와 명시 발주 참조는 없었다. 시작·끝 품목 원문이 일치했다. 공용 인코딩으로 저장한 결과의 원문 해시와 범위를 독립 대조했다.

관측은 양수 숫자 재고·로트 없음이다. 현재 품목은 박스 부자재이며 공용 `tracksQuantityLots`의 로트 필수 대상이 아니다. 따라서 무로트라는 사실만으로 재고 결함·실물 차이로 분류하지 않는다. 과거 차이가 언제 어떤 업무로 바뀌었는지는 이번 제한된 조회로 확인하지 않았다. 나머지 옛 13개 ID와 실측 근거가 없어 원본 TODO 전체 완료로 바꾸지 않는다. 자동 보정이나 운영 자료 변경은 없다.
