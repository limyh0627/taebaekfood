# 원료 사용 저장 후 원장 갱신

2026-10-13. 기존 수정 보존·후속 검증이며 배포하지 않았다.

품목의 원료 사용 기록이 공용 원자 명령으로 확정된 뒤 상위 화면에 원장 재조회를 요청한다. 적용량이 0인 정확한 중복 응답도 성공 결과이므로 갱신한다. 확정 실패나 응답 미확인 때에는 성공한 것으로 표시하지 않고 최초 압착 요청 원문을 보존한다.

이 갱신은 화면이 서버의 확정 원장을 다시 읽게 하는 연결이다. 수량·수율·운영 원장 값을 다시 계산하거나 수정하는 작업이 아니다.

`ItemList.rawUsageLedger.test.tsx`는 성공 적용량 -10/0, 확정 실패, 응답 미확인 및 최초 원문 보존을 검사한다. 재고 writer 프로토콜 연결 후 압착·원장 저장의 정상 경로도 함께 검증한다.
