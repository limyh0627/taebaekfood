# 품목 연결 안내와 목록 화면 정리

현재 목록에서 거래처를 찾지 못한 경우까지 삭제된 품목의 연결 정리 창으로 보냈다. 이제 자사 품목이 확인되면 기존 품목 수정창을 열고, 품목이 목록에서 확인되지 않을 때만 서버 확인으로 안내한다. 목록 부재는 삭제 증거로 사용하지 않는다.

연결 확인 창은 등록된 품목, 보관된 품목, 이미 없어진 연결, 확인 실패를 구분한다. 서버가 품목 부재와 삭제에 필요한 버전·릴리스 정보를 모두 확인한 경우에만 사유와 삭제 입력을 보여준다. 기존 관리자·회사·계정 확인, 최초 요청 보관, 재시도·중단, 응답 지연 보호 및 삭제 요청 본문은 유지한다. 내부 번호와 서버 원문은 접힌 상세에 보존하고 이전 요청이 없으면 복구 영역을 숨긴다.

중복 목록은 기존 버튼으로 여는 별도 창으로 옮겼다. 병합 창과 동시에 열지 않으며 선택을 유지한다. 관리자 품목 행과 품목명은 기존 품목 정보 수정창을 사용한다. 행 안의 별도 버튼·입력과 키보드 동작을 구분하고 박스 행의 진한 배경색을 없앴다. 품목·BOM·원가와 운영 자료는 변경하지 않는다.

관련 시험 5파일 34건이 통과했다. 합성 데이터와 저장 서비스 대역을 사용한 실제 컴포넌트에서 1440px·390px 화면, 품목 열기·등록 품목 확인·중복 창을 검사했다. 외부 요청은 차단했으며 운영 저장 시험은 아니다. 메모리 변환으로 삭제 조건을 무시하면 등록 품목에 삭제 입력이 나타나 시험이 실패하는 것을 확인했다. 최종 앱 타입·관리자 및 직원 앱 빌드와 독립 코드 검수를 통과했다. 첫 타입 검사에서 빠진 표시용 속성 선언을 보완한 뒤 재검증했으며, 첫 빌드의 샌드박스 임시 파일 권한 오류는 같은 빌드를 권한 있는 실행으로 다시 검사했다. 기존 FCM 파일 해시는 유지했다.

검수 마감 당시 이 변경은 작업 브랜치에 있었고 배포·main 푸시·실제 연결 삭제는 수행하지 않았다. 이후 11월 2일 배포 결과는 [배포 확인](deploy-c7b11e3-20261102.md)에 기록했다. 실제 연결 삭제는 수행하지 않았다.
