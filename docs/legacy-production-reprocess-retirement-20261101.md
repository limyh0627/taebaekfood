# 구형 부분 생산 자동 재처리 제거

배포 기준은 `5f53ded`에 기록된 제품 소스 `202d9b6`이다. 이번 후속은 별도 로컬 수정이며 배포 완료로 표시하지 않는다.

현재 관리자 화면은 세대가 있는 생산 명령을 사용한다. 별도의 구형 엔진 호출에는 원료 역처리 → 새 원료 소비 → 생산기록 → 품목·주문 저장을 나눠 실행하는 재처리 분기가 남아 있었다. 중간 실패로 효과가 갈릴 여지가 있어 이 자동 재처리와 사용처 없는 역처리 함수를 제거했다. 현재 운영 화면에서 이 분기의 사고를 재현했다는 뜻은 아니다.

구형 호출에서 생산 완료 시각 없이 원료 처리 흔적이 남으면 예약 전에 서버 주문을 확인해 거절한다. 생산 직전에도 다시 확인한다. 캐시·미확정 로컬 변경·서버 연결 실패·주문 부재를 정상 확인으로 쓰지 않는다. 첫 확인에서 거절하면 예약도 만들지 않고, 두 번째 확인에서 새로 발견하면 기존 정리 경로로 자기 예약만 해제할 수 있다. 원료·완제품·생산기록의 자동 되돌림은 하지 않는다.

정상 최초 생산, 서버에서 이미 완료된 주문의 낡은 화면 중복 호출, 세대가 있는 현재 처리와 기존 원자 취소는 보존한다. 앞선 원료 기록을 발견했는데 수량만 바꿔 자동 재생산하던 시험은 명시적인 지원 계약 변경에 맞춰 거절 및 기존 효과 보존 검증으로 강화했다. 원래 시험은 `git show 5f53ded:src/features/admin/produceIdempotent.test.ts`로 확인할 수 있다.

최종 관련 일반 시험은 17파일 278건 통과, 정확10파일 엄격 타입 검사 통과다. 사전 검사 제거·생산 직전 검사 제거·서버 조회를 캐시 조회로 치환한 세 변이를 실제 업무 assertion이 검출했다. 캐시 조회를 사용했던 중간 후보의 통과 결과는 최종 검증으로 승계하지 않았다. 단위 시험과 소스 검수를 통한 결과이며 새 SDK 운영 재현, 동시 writer에 대한 영구 봉쇄 또는 전체 생산 원자화의 증거로 확대하지 않는다.

같은 최종 후보에서 앱 타입·실서버 컴파일·런타임 로드·관리자와 직원 앱 빌드도 통과했다. 결과는 `work/main-integration-build-a97256f7-6434-42c1-ad45-8e789f6acb4c-result.json`이며 서비스워커 원문 해시를 보존했다. 전체 일반 시험12,241건 통과는 직전 배포 후보의 기록이고, 이번 후속의 새 전체 실행 결과로 사용하지 않는다.

후속은 검증된 정정 증빙의 생산수량 표시와 공개 정정 실행·결과 조회·복구 연결이다. 운영 자료 정정은 별도이며, 이번 제거를 구형 부분 생산의 정상 복구 완료로 보지 않는다.
