# 사용법 도움말과 내 메뉴 설정

2026-10-17 사용자 요청에 따른 신규 기능이다. 앞서 네 조사 산출물의 main 반영 이후 착수하며, 원본 TODO 완료 26개·잔여 17개와 별도로 관리한다.

## 내 메뉴

마이페이지에서 메뉴 숨김, 메뉴 순서, 그룹 순서, 다른 그룹으로 이동, 기본 배치 복원을 제공한다. 마이페이지 진입은 고정한다. 설정은 이 브라우저에서 회사·실제 인증 UID·관리자/직원 화면별로 구분한다. 다른 기기 동기화는 제공하지 않는다.

기존 메뉴의 권한과 동작을 보존한다. 현금출납장과 거래처원장은 같은 화면의 서로 다른 탭이므로 별도 메뉴 ID를 사용한다. QR 인쇄와 거래처 포털도 각각의 동작을 유지한다. 저장값의 중복·알 수 없는 ID는 걸러 내고 신규 메뉴는 기본 그룹에 추가한다. 숨긴 메뉴는 접근 권한을 바꾸지 않는다.

## 사용법 도움말

직원과 관리자 모두 마이페이지에서 질문할 수 있는 대화 화면을 제공한다. 서버에 고정한 실제 앱 사용법과 오류 복구 근거를 바탕으로 답하며, 주문·재고·금액 같은 실제 회사 자료를 조회하거나 업무를 실행하지 않는다. 사용자가 입력한 질문과 제한된 최근 대화는 기존 서버 Secret을 사용하는 AI 모델에 전달한다. 직원 문서는 인증 확인에만 사용하고 모델에 보내지 않는다.

새 `askHelp` 호출은 직원의 현재 인증·회사·재직 상태와 관리자 접근 여부를 확인한다. 직원 화면에는 직원용 근거만 제공한다. 모델이 반환한 근거 ID는 서버 목록과 대조하고 제목·앱 이동 대상은 서버 원본으로 다시 구성한다. 근거가 없으면 확인할 수 없다고 안내한다. 임의 URL·HTML·업무 실행은 지원하지 않는다.

질문은 2,000자, 최근 대화는 최대 6개·각 2,000자·합계 8,000자로 제한한다. 답변은 4,000자와 근거 5개 이내다. AI 요청은 25초 제한이며 자동 재시도하지 않는다. UID별 분당 10회·UTC 일당 100회로 제한하고, 모델 호출에 앞서 트랜잭션으로 사용 횟수를 예약한다. 실패한 모델 호출도 예약 횟수에 포함한다. 전용 `helpChatUsage`에는 질문·답변을 저장하지 않으며 클라이언트 직접 접근은 Rules로 차단한다.

닫기·대화 초기화·계정/회사/화면 모드 전환 뒤 늦게 도착한 답변은 폐기한다. 실패하면 입력을 보존하고 이유와 재시도 방법을 안내한다.

## 검증과 배포

사용자가 후속 선택에서 **사용법·오류 복구 안내부터** 적용하도록 확정했다.

제품 및 시험 16파일을 독립 검수했다. 메뉴 15개(기존 로그아웃 포함), 대화 화면·서비스 25개, 서버 합성 46개, 실제 로컬 Rules·트랜잭션 6개로 고유 집중 검증 92개를 통과했다. 사용량 시험은 익명·양 회사 관리자/직원 접근 거절과 동시 11건 중 정확히 10건 예약·1건 거절을 확인하고 자기 fixture를 정리했다. 초기 동시 요청 시험의 5초 제한 실패는 완료를 기다리는 방식과 제한 시간을 보완한 후 통과했다. 해당 실패를 통과 건수에 합산하지 않는다.

독립 검수에서 기존 직원의 상태값 누락을 새 도움말만 거절하는 회귀를 발견해 기존 로그인과 동일하게 null/undefined를 재직으로 호환했다. 실제 브라우저에서는 질문 전송 후 비활성 입력창 때문에 키보드 포커스가 본문으로 빠지는 회귀를 발견했다. 렌더 직후 대기 중에는 닫기 버튼, 완료·오류 후에는 입력창으로 이동하도록 보완했고 양방향 Tab 순환과 닫은 뒤 원래 버튼 복귀를 보호한다. 각 보호 조건을 제거한 변이를 시험이 검출한 뒤 원문을 복원했다.

총괄이 CUA로 PC와 390픽셀 모바일 폭에서 실제 MyPage·HelpChat 컴포넌트와 동결 SHA를 확인한 AdminApp의 실제 메뉴 카탈로그·NavItem/NavGroup·렌더 식을 사용한 합성 화면을 검수했다. 메뉴 숨김·다른 그룹 이동·순서·새로고침 유지·기본 배치 복원·직원 메뉴·도움말 근거 이동·오류 시 질문 보존·재시도·닫은 요청의 늦은 답변 폐기·포커스 보완을 확인했다. 이는 AdminApp 전체 운영 데이터 mount나 실제 AI 응답 검증과 구분한다. Firebase·알림·AI는 합성 응답으로 대체하고 CSP로 외부 연결을 차단했다. 실기기 검수는 사용자 지시에 따라 제외했다.

서버 빌드와 최종 앱 타입 검사는 종료0이다. 양 앱 최종 빌드는 한 번 수행해 관리자 17.30초·직원 16.40초로 종료0이며, 기존 FCM 원본 bytes와 SHA를 보존했다. 새 사용량 컬렉션을 반영해 필드 사전을 최종 동결 소스에서 한 번 생성·자체 검증했다(컬렉션 95개·기존 모델 필드 739개). 사전의 정적 해석 한계를 유지한다. 배포·공개 파일 대조는 아직 진행 전이다.

운영 전표·재고·금액·기존 설정을 수정하지 않는다. 배포 대상은 최종 검수된 신규 함수와 해당 Rules 변경, 양 Hosting으로 한정하며 다른 함수를 일괄 배포하지 않는다.
