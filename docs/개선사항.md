## 종합 평가 (구조 / 최적화 / 업무 구현)

### A. 구조 체계성 — ★★★☆☆ (보통)
- **좋은 점**: 공통 컴포넌트(PageHeader)·공통 서비스(firebaseService)·공통 유틸(lotUtils/rawReceipt/formula) 분리, 구독 중앙화(useAppData), 타입 단일 파일(types.ts), feature 폴더 구조.
- **문제 점**:
  - **God component**: `HaccpChecklist`·`AdminApp`·`TradeStatement`·`ItemList` 초대형(수천 줄). 한 파일에 상태·핸들러·렌더·비즈니스 로직이 다 몰림. → 재고 엔진(생산/출고)은 `reconcileOrderStock` 등으로 일부 정돈했으나 여전히 AdminApp 안에 있음.
  - **다중 진실 소스**: item.stock↔lots(원료는 lots 단일화 ✅), PRODUCT_FORMULA↔item_formula(우선순위 통일 🟡), Standard_Price↔price(통일 ✅).
  - **deprecated 이중 스키마 다수**(types.ts) → 곳곳에서 하위호환 분기.
  - **테스트 0개**. 재고/원가 같은 정합성 핵심 로직에 회귀 방지 장치 없음.

### B. 최적화(읽기/성능) — ★★★☆☆ (양호하나 함정 있었음)
- **좋은 점**: 채팅·파레트·수불부 같은 **활동성 컬렉션**은 최근 N일 구독으로 읽기 비용 통제. lot FIFO·수율 계산 등 도메인 연산 정돈됨.
- **문제 점**:
  - 🐞 **[2026-07-11 발견·수정] 전표(issuedStatements)가 "최근 7일"로만 구독되고 있었음.** 채팅용 7일 패턴을 **재무 원장**에 잘못 적용 → 손익·현금흐름·미수금이 전부 최근 7일 전표만 집계(예: 7월 매출 6,329만이 3,743만으로 축소 표시). **전체 구독으로 변경 완료 ✅.** → 재무·원장 성격 컬렉션은 recent 구독 금지 원칙.
  - `purchaseOrders`·`items` **전체 라이브 구독** → 누적 시 매 세션 전량 읽기(#9). 특히 items는 `lots` 배열로 페이로드 큼(소진 lot 정리로 완화 ✅).
  - **native alert/confirm 다수** — 블로킹·비일관 UX.

### C. 실제 업무 구현 — ★★★★☆ (넓게 구현, 제조 정합성 보강됨)
- **좋은 점**: 원료 입고/사용/lot·매출/매입/비용 전표·세금계산서·배송·재고·생산실적·HACCP·인사까지 업무 범위 매우 넓음. 참기름 제조업 특유의 **원료 배합(BOM)·FIFO 차감·수불부**가 실제 워크플로우로 반영됨.
- **최근 보강(2026-07-10~11)**:
  - **생산/출고 재고 분리 ✅**: 작업완료=생산처리(원료·부자재 차감 + 완제품 재고 +), 출고=재고 −, 되돌리기 지원(#4 해소).
  - **즉석배합(phantom) 반제품 ✅**: 완제품 출고 시 배합비대로 원료 재귀 전개 차감(#6 상당 부분).
  - **원료 배합·수율 편집 UI ✅**(품목 정보 수정).
  - **간접법 현금흐름표 ✅**(월별/기간).
- **남은 미흡(제조 정합성)**:
  - **반제품 자체 "생산" 이벤트로의 원료 차감**은 phantom 전개에 한정(선제조형 반제품 생산 차감은 미구현) 🟡.
  - **실사조정이 lot 이력 뭉갬**(#3) — guard는 고쳤으나 "기존 lot 유지+차액" 방식은 미완 🟡.
  - **월별 품목별 재고 스냅샷 없음**(#10) → 정확한 월 재고평가 어려움.
  - OEM(완사입/임가공)·박스/낱개 variant 재고 미구현.

**한 줄 총평**: *제조·추적 정합성(생산/출고 분리·phantom·역추적)은 크게 보강됨. 남은 축은 (1) 초대형 컴포넌트·다중 진실 소스 정리, (2) 실사 lot 이력·월별 품목 스냅샷·OEM/variant 재고.*

## 🔴 높음 — 데이터 정합성 / 리스크

### 1. 로트(lot) 무한 증가 → 문서 비대화 — ✅ 완료
- 소진 lot을 6개월 보존 후 정리(`pruneDepletedLots`, `src/shared/lotUtils.ts`), `mutateRawMaterialLots` 쓰기 전 적용. 소비 이력은 주문 `rawConsumedLots` 스냅샷에 보존되어 추적성 유지.

### 2. 재고 단일 소스(single source of truth) — ✅ 완료
- 원료(raw)·wip 벌크 홀더는 화면도 `lots` 합계(`lotStockInUnit`)를 직접 읽음(`ItemList` `isRawHolder`/`displayStockOf`). stock 필드값과 무관하게 lots가 유일 기준. 깨분참기름류 "수불부는 맞는데 화면 0" 불일치 해소.

### 3. 실사조정이 lot 이력을 뭉갬 — 🟡 부분
- 수율 자동파생 오작동 guard는 `type !== 'correction'` 으로 수정(실사정정이 phantom 입고 만들던 문제 해소). **다만** 실사=기존 lot 유지 + 차액 조정 lot만 추가하는 방식은 아직 미완 → 실사 이전 공급처·입고일 추적 단절 가능성 잔존.
- **방향**: `commitStockEdit`/`adjustRawLots`에서 기존 lot 보존 + 차액 lot 추가(음수면 FIFO 차감).

### 4. 생산 = 배송완료 가정 (선제조 미반영) — ✅ 완료
- 상태 전환에 따라 재고를 **생산/출고로 분리**: 작업완료(DISPATCHED)=원료(FIFO 로트)·부자재 차감 + 완제품 재고 +N, 출고(SHIPPED)=완제품/상품 재고 −N. 되돌리기 시 뺀 만큼 복원(원료는 `rawConsumedLots`로 로트 복원). `reconcileOrderStock`/`changeOrderStatus` 단일 진입점.
- **남은 것**: 주문과 무관한 순수 "선제조 재고풀"(주문 없이 미리 생산)은 아직 주문귀속형만 → ProductionManager 연동 확장 여지.

## 🟡 중간 — 완성도

### 5. 역추적(lot → 제품, 리콜) — ✅ 완료
- ProductionManager에 **로트 역추적·리콜 패널** 추가. 주문 `rawConsumedLots` 스냅샷 기반으로 "특정 로트가 소비된 주문/제품" 조회.

### 6. 반제품(wip) 원료 차감 — 🟡 대부분 완료
- 완제품 출고 시 **phantom 반제품**(즉석배합)은 배합식 재귀 전개(`buildFormula`)로 하위 원료까지 차감. wip 벌크 홀더(볶음참깨 등)는 완제품 출고 시 로트 차감됨.
- **남은 것**: 선제조형 반제품을 "생산" 이벤트로 별도 제조하며 원료 차감하는 경로는 미구현.

### 7. BOM 이중 소스 — 🟡 부분
- 차감·표시 모두 `buildFormula`로 **item_formula 우선 + PRODUCT_FORMULA 폴백** 통일. 코드 하드코딩은 폴백/시딩용으로 축소.
- **남은 것**: PRODUCT_FORMULA 완전 제거(=item_formula 단일화)는 데이터 시딩 후.

### 8. 단일/다품목 발주카드 혼재 — ⬜ 미착수
- 재고현황 "발주내역 입고대기"가 단일품목 전용 렌더 → 다품목 PO 누락 가능. `poLines(po)` 기반 통일 필요.

### 9. purchaseOrders / items 전체 라이브 구독 — ⬜ 미착수
- `purchaseOrders`는 상태/기간 제한 구독(예: `status != 'received'` 또는 최근 N개월) 검토. (전표는 재무 원장이므로 전체 구독 유지 — B 참고)

### 10. inventorySnapshots가 총액만 저장 — ⬜ 미착수
- 재고 마감 스냅샷이 `{ yearMonth, value(총액) }` 만 저장 → 품목별 수량·평가액 스냅샷 없음. 월별 상세 손익/재고 분석 제약. (현금흐름표 재고증가 계산도 이 총액 스냅샷에 의존)

## 🔵 구조 / 기술부채 (리팩터링) — ⬜ 대체로 미착수

### 11. God component 분해
- 초대형 컴포넌트에 상태+핸들러+렌더+로직 집중. 재고 엔진은 `reconcileOrderStock`/`buildFormula`로 일부 함수화했으나 여전히 AdminApp 내부.

### 12. 도메인 계층 부재
- 재고 차감·전표·입고·원가 동기화가 UI 컴포넌트 render 클로저에 흩어짐. `inventory`/`ledger` 순수 도메인 모듈로 규칙 단일화 필요.

### 13. 재고 변경 로직 분산
- 원료 재고 변경을 단일 헬퍼(`adjustRawLots`/`mutateRawMaterialLots`)로 강제. 생산/출고는 `reconcileOrderStock`로 일원화됨(부분 개선).

### 14. 테스트 0
- `lotUtils`(FIFO/혼합/차감)·`formula`(kg 환산/배합)·`buildFormula`(재귀 전개) 순수 함수부터 단위 테스트 권장.

### 15. deprecated 이중 스키마 정리 — 🟡 부분
- partner_item(Item_ID/Partner_ID/Standard_Price → itemId/partnerId/price) 통일 완료. 나머지(boxSize/defaultBoxConfig, spec/용량 등) 잔존.
